Everything below works and is tested against real windows and a real keyboard, but nothing has been played through a full match yet. Use it to see what the approach does, not during something that matters, and read the anti-cheat note before taking it online.

01 — Zoom

Magnify the window. The game never knows.

Hold the bind and a live DWM copy of the window is magnified on an overlay. The game is never moved and never told, so it keeps rendering at its own resolution. Scroll while holding to change the factor.

Try it on the window above: press and hold, or hold Z. Scroll to change the factor.

02 — What it does

01

Place any window exactly

Quick halves, ×4 ×6 ×8 ×10 split cells, aspect presets or typed X Y W H, drawn on a to-scale preview of your monitor.

02

Borderless on demand

Strips the caption and frame and keeps the rendered resolution.

03

Multiple instances

Two copies of the same game are told apart by window handle and process id, and numbered #1 #2 #3.

04

Hotkeys that behave

A key or a mouse side button. The bind only fires while the target is in front, and the key is held back from the game. The master switch and F8 never eat their key.

05

Hold the layout

Pin a window and its layout is re-asserted when the game moves it back on Alt-Tab.

06

Picks up where you left off

The setup comes back next launch. Named profiles find their windows again by executable, so they survive a restart and a changed title.

03 — How it works

Four documented APIs. Nothing else.

  1. Discovery, placement, borderlessEnumWindows · SetWindowPos · styles
  2. Pixel-accurate framingDWMWA_EXTENDED_FRAME_BOUNDS
  3. ZoomDwmRegisterThumbnail + rcDestination
  4. Scope lens, HUD layersrcSource set to a regionplanned
  5. Curved screen, CRT, motion blurWindows.Graphics.Capture → D3D11 → HLSLplanned
  6. Custom display modesNVIDIA NvAPIplanned

Reading another process’s memory

A caution that matters. Some kernel-level anti-cheats object to topmost overlay windows and to another process moving the game window, however it is done. Check your game’s rules before using tlk-grid online.

05 — Get it

One exe. F8 undoes everything.

  • Windows 10 1903 (build 18362) or newer, 64-bit
  • A GPU with Desktop Window Manager enabled
  • WebView2 runtime, preinstalled on Windows 10 and 11
  • The game in windowed or borderless windowed mode
