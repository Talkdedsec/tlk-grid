# Code of conduct

Be decent. Comment on code, not on people. Assume the person on the other end is
trying to help.

Not welcome: personal attacks, harassment, or dragging unrelated arguments into
the tracker.

If something crosses that line, write to

on what happened, the response ranges from a word in a thread to a block.
